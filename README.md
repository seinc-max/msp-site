# Trueline IT - Site (Production Scaffold)

This directory contains a minimal Next.js project scaffold designed for a fast, static export deployment via Cloudflare Pages.

How to run locally:
- npm install
- npm run build
- npm run export
- Open the output in dist (or out) depending on config

Deployment:
- Connect to GitHub, push to main
- Cloudflare Pages will auto-deploy from GitHub
