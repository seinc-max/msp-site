FAQ

Will this eliminate no-shows?+
No. Confirms and reminders can help reduce no-shows; they don’t remove them. Results vary by trade, deposit policy, and how you handle exceptions.
Is this for healthcare / clinical offices?+
We stay off clinical EHR workflows. This kit is for field and shop calendars in service businesses. Ask on the call if you’re unsure.
Is this software I have to configure myself?+
No. We install and manage the sequence. You’re not left configuring alone.
Can clients reschedule from the text?+
Yes — within rules you set (reply keywords, link, or “call us”). We design that with you.
Is this the price I’ll pay?+
Yes for the kit as described — $397 setup + $149/mo CAD. Media spend is separate. The fit call confirms fit; add-ons (extra lines, locations, overage) are quoted only if needed.
Does this include Meta ads?+
No. Meta spend is closed on our side right now. This page is confirm + reminder SMS only.
